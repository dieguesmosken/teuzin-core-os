Teuzin Core OS

A lightweight OS for home infrastructure on the BTT Pi V1.2 (Allwinner H616, 1 GB RAM): Debian 13 minimal, 6.18 LTS kernel, native services and manual-only updates.

Debian 13 minimal6.18 LTS kernelBy Teuzin Labs
Under development. The base image builds on CI but is not yet tested on hardware. Pi-hole, Tailscale, Wake-on-LAN and the Teuzin Core panel are planned, not implemented.

Install guide

  1. From the chosen release, download the .img.xz file and SHA256SUMS-images.txt.
  2. Verify the checksum: 
    sha256sum -c SHA256SUMS-images.txt
  3. Decompress: 
    xz -d IMAGE-NAME.img.xz
  4. Flash to a new microSD (Balena Etcher, or Disks on Linux). Never flash the old recovery card, and double-check the selected device.
  5. First boot: serial console or SSH. Credentials and first-boot details will be documented after bench testing.
